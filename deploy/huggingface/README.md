# Pipeline Medic demo

Replay of real runs of [Pipeline Medic](https://github.com/SreyaThota/pipeline-medic):
an agent graph that diagnoses a failed CI run, rates its risk and proposes a
ticket or notification, then waits for a human before anything runs.

The five runs were recorded from the real graph on held-out logs (retrieval
vote and rubric risk stage, no LLM); approving a run shows its recorded
dry-run result. Nothing executes and no model runs on this Space. The same
page is the main demo at <https://sreyathota.github.io/pipeline-medic/>.

This folder is generated by `deploy/huggingface/build_space.py` in the GitHub
repository.
