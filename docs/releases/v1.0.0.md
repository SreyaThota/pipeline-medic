# Pipeline Medic v1.0.0

An AI agent that diagnoses failed CI/CD runs, rates their risk and proposes a
ticket or alert, then waits for a human before anything runs.

## What's new

- **Interactive demo.** `streamlit run demo/app.py` runs the real agent graph
  on real failed CI runs (or your own pasted log) and shows each stage with
  its latency: secret redaction, line-referenced evidence, retrieval-based
  diagnosis with similar past failures, rubric risk and the proposed tool
  calls. Approve or reject to resume the paused run and see the dry-run
  result and the audit trail.
- **Deployable.** A CPU-only Docker image for a free Hugging Face Space, plus
  a GitHub Actions workflow that keeps the Space in sync with `main`.
- **Docs.** A design document (`docs/DESIGN.md`), a changelog, an MIT licence
  and a rewritten README.

## Numbers (unchanged from v0.9, all reproducible from the repo)

- Retrieval on the last 15 log lines: cross-repo Recall@1 0.413 vs 0.217 for
  the whole log.
- Whole graph on 72 held-out runs: 27.8% fully correct with the rule-based
  risk stage vs 11.1% with a prompted LLM; diagnosis is the first wrong stage
  in 48 of 72 runs.
- GraphRAG (+0.028 MRR, 95% CI −0.088 to +0.146) and a LoRA classifier
  (0.52–0.59 vs 0.50 accuracy, not significant) were measured and not adopted.

## Safety

Logs and model output are untrusted, tool choice never comes from log text,
secrets are redacted before any model call, and nothing executes without
human approval. 80 security tests run in CI.
